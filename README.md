# Бэкенди «Суши Pizza Тайм»

Сервери воқеӣ барои сомонаи «Суши Pizza Тайм» — **бе ниёз ба `npm install`**,
танҳо бо Node.js core (`http`, `fs`, `path`). Маълумот дар файлҳои JSON
(`db/*.json`) нигоҳ дошта мешавад — барои демо ва MVP кофист.

## Оғоз кардан

Ба шарте ки Node.js (нусхаи 18 ё болотар) насб бошад:

```bash
node server.js
```

Сервер дар `http://localhost:4000` кор мекунад. Дар терминал парол ва
адреси admin панел нишон дода мешавад.

Хоҳед портро иваз кунед ё пароли админро тағйир диҳед:

```bash
PORT=5000 ADMIN_PASSWORD=maxfiy123 node server.js
```

## Сохтори лоиҳа

```
server.js            — сервери асосӣ, ҳамаи роутҳо
config.js            — порт, пароли админ, суммаи ҳадди ақали фармоиш
db/store.js           — хондан/навиштани файлҳои JSON
db/*.json              — "база маълумот" (маҳсулот, фармоишҳо, ва ғ.)
routes/products.js    — каталог, категория, CRUD-и маҳсулот
routes/orders.js      — эҷод/дидан/тағйири статуси фармоиш (нархро дар сервер аз нав ҳисоб мекунад)
routes/promo.js        — санҷиши промокод
utils/http.js          — ёрдамчиҳои JSON response, CORS, хондани body
utils/auth.js          — токени содаи админ (дар хотира, на дар база)
scripts/reseed.js      — аз нав пур кардани db/*.json аз scripts/seed-source.js
public/                — фронтенди сомона (HTML/CSS/JS), АЛЛАКАЙ пайваст ба API — сервер онро худаш хизмат мерасонад
```

## Кушодани сомона (фронтенд + бэкенд якҷоя)

```bash
node server.js
```

Баъд дар браузер кушоед: **http://localhost:4000**

Ҳамин лаҳза сомона тавассути ҳамин сервер кор мекунад: меню, категорияҳо,
акцияҳо — ҳама аз `/api/*` меоянд; фармоиш ба сервер фиристода мешавад ва
дар `db/orders.json` сабт мешавад. Корзина/избранное/адрес ҳанӯз дар
`localStorage` (шахсӣ барои ҳар браузер), аммо **худи фармоиш ва статуси
он манбаи ягона — сервер аст**.

## API-и асосӣ

### Оммавӣ (бе авторизатсия)

| Метод | Роут | Тавзеҳ |
|---|---|---|
| GET | `/api/products?category=rolls&search=лосось` | Рӯйхати маҳсулот бо филтр |
| GET | `/api/products/:id` | Як маҳсулот |
| GET | `/api/categories` | Категорияҳо |
| GET | `/api/addon-groups` | Соус/қатъиёт/нӯшокиҳои иловагӣ |
| GET | `/api/promotions` | Акцияҳо |
| GET | `/api/delivery-zones` | Зонаҳои интиқол ва нарх |
| GET | `/api/cities` | Рӯйхати шаҳрҳо |
| POST | `/api/promo/validate` `{code, subtotal}` | Санҷидани промокод |
| POST | `/api/orders` | Эҷоди фармоиш (нигаред поён) |
| GET | `/api/orders/:id` | Дидани як фармоиш (барои мизоҷ — бо рақами фармоиш) |

### Танҳо барои админ (лозим аст `Authorization: Bearer <token>`)

| Метод | Роут | Тавзеҳ |
|---|---|---|
| POST | `/api/admin/login` `{password}` | Гирифтани токен |
| GET | `/api/admin/orders` | Ҳамаи фармоишҳо |
| PATCH | `/api/admin/orders/:id` `{status}` | Тағйири статус |
| POST | `/api/admin/products` | Иловаи маҳсулоти нав |
| PUT | `/api/admin/products/:id` | Тағйири маҳсулот |
| DELETE | `/api/admin/products/:id` | Нест кардани маҳсулот |

Статусҳои дуруст: `Новый`, `Принят`, `Готовится`, `Передан курьеру`,
`Доставлен`, `Отменён`.

### Намунаи эҷоди фармоиш

```bash
curl -X POST http://localhost:4000/api/orders \
  -H "Content-Type: application/json" \
  -d '{
    "items":[{"productId":1,"qty":2,"addons":{"sauce":["s1"]}}],
    "fulfillment":"delivery",
    "address":{"city":"Москва","street":"Тверская","house":"1","flat":"5"},
    "name":"Азиз","phone":"+79991234567","payment":"card-online",
    "promoCode":"WELCOME10"
  }'
```

Диққат: **нарх ва скидка ҳамеша дар сервер аз нав ҳисоб карда мешаванд**
(аз рӯи `db/products.json` ва `db/promo-codes.json`) — қиматҳое, ки
фронтенд мефиристад, эътимод карда намешаванд. Ин муҳим аст, то мизоҷ
натавонад нархро аз браузер тағйир диҳад.

### Намунаи вуруди админ

```bash
TOKEN=$(curl -s -X POST http://localhost:4000/api/admin/login \
  -H "Content-Type: application/json" -d '{"password":"admin123"}' \
  | python3 -c "import json,sys;print(json.load(sys.stdin)['token'])")

curl -s http://localhost:4000/api/admin/orders -H "Authorization: Bearer $TOKEN"
```

## Фронтенд аллакай пайваст аст

`public/index.html` + `public/app.js` + `public/styles.css` — ҳамон
сомонае, ки қаблан дидед, аммо ҳоло ба ҷои `localStorage` барои маҳсулот/
фармоиш аз ин API истифода мебарад:

- Меню, категория, акция, зонаҳои интиқол — `fetch()` мешаванд ҳангоми
  боркунии саҳифа (экрани "Загружаем меню…" то боркунӣ намоиш дода мешавад)
- Промокод — ҳар боре ки истифода мешавад, ба `/api/promo/validate` санҷида мешавад
- Тугмаи «Подтвердить заказ» — `POST /api/orders` мефиристад; нарх ва
  скидка аз ҷавоби сервер гирифта мешаванд (на аз ҳисоби браузер)
- «История заказов» — рӯйхати ID-ҳо дар `localStorage`, аммо статус ва
  тафсилот ҳар дафъа аз сервер тоза гирифта мешавад — агар админ статусро
  тағйир диҳад, мизоҷ онро дар саҳифаи худ мебинад

Агар фронтендро дар домени дигар (на дар ҳамин сервер) ҷойгир кунед, дар
`public/app.js` хатти аввали `const API_BASE = "";` -ро ба адреси пурраи
бэкенд иваз кунед, масалан `const API_BASE = "https://api.sushipizzatime.ru";`

## Панели админ (визуалӣ)

Дар браузер кушоед: **http://localhost:4000/admin.html**

Парол (аслӣ): `admin123` (тағйир диҳед бо `ADMIN_PASSWORD=...`)

Дар панел:
- **Заказы** — рӯйхати ҳамаи фармоишҳо, тағйири статус бо як клик (Новый → Принят → Готовится → Передан курьеру → Доставлен, ё Отменён)
- **Товары** — ҷадвали ҳамаи маҳсулот, тугмаи «+ Добавить товар», ✎ барои таҳрир, ✕ барои нест кардан

Токени вуруд дар `sessionStorage` аст — баъд аз пӯшидани таб бекор мешавад (бояд дубора ворид шавед).

### Боркунии акси воқеӣ

Дар шакли иловаи/таҳрири маҳсулот, тугмаи «📷 Загрузить фото»-ро зер кунед ва акси таомро аз телефон/компютер интихоб кунед. Акс худкор фишурда мешавад (то 900px, JPEG) ва дар `db/products.json` ҳамчун base64 нигоҳ дошта мешавад — файли алоҳида лозим нест. Агар акс нагузоред, эмодзи+градиенти пешфарз истифода мешавад.

⚠️ Дар хидматҳои ройгони мисли Render, файли `db/products.json` (бо ҳамроҳи аксҳо) метавонад баъд аз ҳар деплойи нав ба ҳолати аслии GitHub баргардад — яъне агар аксро тавассути сомонаи зинда илова кунед, баъд аз деплойи навбатӣ гум мешавад, магар он ки онро низ ба GitHub бор кунед (`db/products.json`-ро аз сомона зеркашӣ карда ба репозиторий гузоред) ё ба база доимӣ (Postgres) гузаред.

## Маҳдудиятҳои демо-версия (муҳим барои донистан)

- **База маълумот файли JSON аст, на PostgreSQL/MySQL.** Барои сомонаи
  воқеӣ бо бисёр фармоишҳои ҳамзамон тавсия мешавад ба SQLite ё Postgres
  гузаред — сохтори код (`routes/*.js`) тағйир намеёбад, танҳо
  `db/store.js`.
- **Токени админ дар хотира (RAM) аст** — баъд аз рестарти сервер бекор
  мешавад. Барои production JWT ё сессияи доимӣ лозим аст.
- **Пардохти воқеӣ пайваст нашудааст** — майдони `payment` танҳо
  сабт мешавад, воқеан пул гирифта намешавад. Барои ин провайдери
  пардохт (ЮKassa ва монанди он) лозим аст.
- **CORS кушода аст ба ҳама** (`*`) — барои демо хуб, барои production
  бояд танҳо домени сомонаи худро иҷозат диҳед (дар `utils/http.js`).
